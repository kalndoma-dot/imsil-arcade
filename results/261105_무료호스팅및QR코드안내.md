# 임실 청소년 문화의집 무료 웹 호스팅 및 스마트폰 QR 코드 배포 가이드 보고서
본 보고서는 임실 청소년 문화의집 디지털 아케이드 프로젝트를 무료 웹 호스팅에 업로드하고, 스마트폰으로 간편하게 접속할 수 있도록 QR 코드를 연동하는 구체적인 실무 절차를 정리한 문서입니다.

## 1. 무료 웹 호스팅 추천 방식 2가지
별도의 서버 비용이나 유지비 없이 영구적으로 무료 운영 가능한 최적의 호스팅 방식입니다.
- **방식 1: Netlify Drop (가장 쉽고 빠름 · 초보자 추천)**
  - 특징: Git 명령어 없이 브라우저 드래그 앤 드롭만으로 10초 만에 웹 주소 발급.
  - 배포 절차:
    1. Netlify 공식 홈페이지(netlify.com)에서 무료 회원가입을 진행합니다.
    2. 브라우저로 `app.netlify.com/drop`에 접속합니다.
    3. 현재 프로젝트 폴더(`d:\App project\Vibe Coding`) 전체를 브라우저 점선 영역으로 끌어다 놓습니다.
    4. 즉시 `https://random-name.netlify.app` 형태의 고유 주소가 생성되며, 사이트 설정(Site settings)에서 `https://imsil-arcade.netlify.app` 등 원하는 이름으로 변경할 수 있습니다.
- **방식 2: GitHub Pages (가장 안정적 · 표준 방식)**
  - 특징: 깃허브 공식 무료 정적 호스팅 서비스로 트래픽이 넉넉하고 신뢰성이 높음.
  - 배포 절차:
    1. GitHub(github.com)에서 새 저장소(`imsil-arcade`, Public 설정)를 만듭니다.
    2. 프로젝트 폴더 내 파일들을 해당 저장소의 `main` 브랜치에 업로드합니다.
    3. 저장소 상단의 `Settings` 탭 > 좌측 메뉴 `Pages`로 이동합니다.
    4. `Build and deployment` 섹션에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 선택하고 `Save`를 누릅니다.
    5. 1~2분 후 `https://[깃허브ID].github.io/imsil-arcade/` 형태의 무료 웹 주소가 개설됩니다.

## 2. 통합 포털 내 실시간 QR 코드 시스템 구축 결과
스마트폰 사용자들이 즉각적으로 접속할 수 있도록 포털 사이트 자체에 동적 QR 코드 생성기를 내장했습니다.
- **원클릭 QR 코드 모달 기능(`index.html`)**
  - 사이트 상단에 `[📱 스마트폰 접속 QR코드]` 버튼을 신설했습니다.
  - 버튼을 누르면 배포된 URL을 바탕으로 실시간 QR 코드가 화면에 고해상도로 팝업 출력됩니다.
  - 센터 PC나 키오스크를 보던 학생들이 스마트폰 기본 카메라 앱으로 화면의 QR 코드를 비추면 즉시 모바일 웹페이지로 연결됩니다.
  - 배포 주소 직접 입력 및 변경 기능, 클립보드 링크 복사 버튼을 함께 탑재했습니다.

## 3. 스마트폰 모바일 터치 최적화 완료 내역
청소년들이 스마트폰 화면에서도 불편함 없이 게임을 즐길 수 있도록 모바일 터치 인터랙션을 완비했습니다.
- **두더지 잡기(`김성원 whack_a_mole.html`)**: 모바일 손가락 터치(`touchstart`/`touchmove`) 이벤트를 연결하여 터치 즉시 뿅망치가 휘둘러지도록 지연 시간(딜레이)을 제거했습니다.
- **풍선 터트리기(`양도윤 balloon_archery.html`)**: 화면 터치 위치를 실시간 감지하여 손가락으로 화면을 누르는 곳으로 다트가 정확히 발사되도록 터치 조작계를 적용했습니다.
- **격자 보물찾기(`권찬우 보물찾기.html`)**: 스마트폰에서 우클릭이 어려운 점을 감안하여 상단에 `[⛏️ 파내기 모드] / [🚩 깃발 모드]` 원터치 전환 버튼을 탑재했습니다.

## 4. 현장 안내판 제작 및 활용 팁
- 배포된 주소의 QR 코드를 캡처하거나 다운로드하여 A4 크기의 '임실 청소년 문화의집 모바일 게임존 안내 포스터'를 인쇄합니다.
- 문화의집 입구 로비, 컴퓨터실, 휴게실 등에 부착해 두면 센터를 방문하는 모든 청소년들이 자신의 스마트폰으로 자유롭게 게임을 즐길 수 있습니다.
